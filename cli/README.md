# ktw — KinoTeka Watch в терминале

Тот же поиск и те же плееры, что на сайте, но полноэкранным интерфейсом в
терминале и с выводом потока в mpv.

```
╭────────────────────────────────────────────────────────────────╮
│  ▄▄▄▄▄▄▄▄▄▄▄   Игра престолов                                  │
│  ██ обложка ██  Game of Thrones                                │
│  ▀▀▀▀▀▀▀▀▀▀▀   2011 · фэнтези, драма · 55 мин · ★ 9.2          │
│                                                                │
│                Серии                                           │
│                ❯ S2E1  Север помнит              2012-04-01    │
│                  S2E2  Ночные земли              2012-04-08    │
╰────────────────────────────────────────────────────────────────╯
                  ↑↓ выбор  ·  Enter дальше  ·  Esc назад
```

## Установка одной командой

```sh
curl -fsSL https://raw.githubusercontent.com/FLEXIY0/KinoTeka-Watch/main/cli/install.sh | sh
```

> Пока ветка не влита в `main`, ставить надо с неё:
>
> ```sh
> curl -fsSL https://raw.githubusercontent.com/FLEXIY0/KinoTeka-Watch/claude/site-player-cli-9ly8ks/cli/install.sh \
>   | KTW_BRANCH=claude/site-player-cli-9ly8ks sh
> ```

Скрипт сам поставит недостающее (Node.js, mpv, chafa, puppeteer с Chromium),
скачает исходники в `~/.local/share/ktw`, слинкует команду `ktw` в
`~/.local/bin` и спросит ключ API. Повторный запуск обновляет установку.

Это чистый POSIX sh без systemd, так что Devuan, Alpine, Void и прочие
не-systemd системы проходят так же, как Debian или Arch. Пакеты ставятся через
apt/apk/dnf/yum/pacman/zypper/xbps/brew — что найдётся; root запрашивается
через sudo, doas или su. Куда ставить, можно переопределить:

```sh
KTW_HOME=~/opt/ktw KTW_BIN=~/bin sh install.sh
```

Если репозиторий уже склонирован, запусти `sh cli/install.sh` из его корня —
скрипт возьмёт исходники на месте, ничего не скачивая.

### Что нужно

| Что | Зачем | Обязательно |
| --- | --- | --- |
| Node.js 18+ | сам клиент | да |
| mpv | воспроизведение | да |
| puppeteer | извлечение потока из плеера | да |
| chafa | обложки в терминале | нет, без него рамка с буквой |

Вместо chafa подойдёт ImageMagick — если он есть, обложки рисуются полублоками.

## Как пользоваться

```sh
ktw                          # полноэкранный интерфейс
ktw матрица                  # сразу с запросом в поле поиска
ktw 301                      # по id Кинопоиска
ktw https://www.kinopoisk.ru/film/301/
```

Дальше всё интерактивно: печатаешь название — под полем появляются похожие
фильмы, Enter выбирает. Для сериала спросит сезон и серию, потом плеер, потом
озвучку (если их несколько — у Alloha и Collaps их бывает под два десятка), и
только потом достанет поток и отдаст его mpv. После выхода из mpv возвращает к
списку серий, так что следующую можно включить в два нажатия.

| Клавиши | Действие |
| --- | --- |
| `↑` `↓` | выбор в списке |
| `PgUp` `PgDn` `Home` `End` | быстрая прокрутка длинных списков |
| `Enter` | дальше |
| `Esc` | шаг назад, из поиска — выход |
| `Ctrl+U` `Ctrl+W` | очистить поле / стереть слово |
| `Ctrl+C` | выход отовсюду |

### Опции

| Опция | Что делает |
| --- | --- |
| `-p, --player <тип>` | взять плеер по имени, без выбора вручную |
| `-t, --translation <имя>` | взять озвучку по части названия |
| `-s, --season <n>` | номер сезона |
| `-e, --episode <n>` | номер серии |
| `--iframe` | не искать поток, просто вывести ссылку на плеер |
| `--no-mpv` | найти поток и вывести ссылку с готовой командой mpv |
| `--json` | машинный вывод для скриптов |
| `--plain` | построчный режим без полноэкранного интерфейса |
| `--headful` | показать окно браузера — видно, на чём споткнулось извлечение |
| `--timeout <мс>` | сколько ждать поток, по умолчанию 40000 |
| `--key <ключ>` | ключ API Кинопоиска |

Всё после `--` уходит напрямую в mpv:

```sh
ktw матрица -- --fs --sub-file=ru.srt
```

Флаги `--json`, `--no-mpv`, `--iframe`, `--plain` и запуск без терминала
переключают в построчный режим: служебный вывод идёт в stderr, ссылка и JSON —
в stdout, поэтому пайпы работают.

```sh
ktw матрица --no-mpv | xargs -I{} yt-dlp {}
```

### Ключ API

Бесплатный ключ выдаёт [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech).
Берётся, в порядке приоритета, из:

1. `--key <ключ>`
2. переменной окружения `KINOPOISK_API_KEY`
3. файла `kinopoisk-key.js` в корне проекта (того же, что использует сайт локально)
4. `~/.config/ktw/config.json`

### Переменные окружения

| Переменная | Смысл |
| --- | --- |
| `KTW_POSTER=off` | не рисовать обложки |
| `KTW_ASCII=1` | рамки и спиннеры из ASCII вместо Unicode |
| `NO_COLOR=1` | без цвета |
| `PUPPETEER_EXECUTABLE_PATH` | свой Chromium вместо скачанного puppeteer |
| `KTW_KINOBOX_API` | своё зеркало списка плееров |

## Как это работает

Сайт использует `kinobox.js`, который дёргает `api.kinobox.tv/api/players?kinopoisk=<id>`
и получает список балансеров с адресами iframe. CLI повторяет ту же цепочку:

```
запрос ─► kinopoiskapiunofficial.tech  ─► выбор фильма, сезона, серии
       ─► fbphdplay.top/api/players    ─► выбор плеера и озвучки
       ─► headless Chromium + iframe   ─► ловим .m3u8 в сетевых запросах
       ─► mpv                          ─► смотрим
```

### Зеркала списка плееров

`api.kinobox.tv` отвечает не отовсюду: с части адресов он рвёт соединение или
отдаёт 5xx. Поэтому первым опрашивается `fbphdplay.top/api/players` — то самое
зеркало, с которого сайт грузит `kinobox.js`, и отдаёт оно ровно тот же JSON.
Если оно молчит, следующим идёт официальный `api.kinobox.tv`; своё зеркало
можно поставить первым через `KTW_KINOBOX_API`.

Ответ богаче, чем кажется: у каждого балансера свой список озвучек, и у части
из них (Alloha, Veoveo) **у каждой озвучки собственная ссылка на iframe** —
`&translation=93` и так далее. Поэтому озвучка выбирается до извлечения потока,
а не переключается внутри плеера.

Прямую ссылку на поток балансеры в открытом виде не отдают — её собирает их
обфусцированный JS уже в браузере, и у каждого балансера он свой и постоянно
меняется. Поэтому вместо разбора каждого по отдельности iframe открывается в
headless Chromium, а из его сетевых запросов забирается первый `.m3u8`
(`.mpd`/`.mp4` — как запасной вариант). Реклама и превью отсеиваются по маске
адреса, а Referer для mpv берётся из фрейма, который запросил поток, — без него
CDN отдаёт 403.

### Файлы

```
cli/
  install.sh      — установщик (POSIX sh)
  ktw.js          — разбор аргументов, построчный режим
  lib/
    app.js        — экраны интерфейса и переходы между ними
    tui.js        — движок: кадры, клавиши, списки, рамки
    ansi.js       — цвета, ширина строк, рамки
    poster.js     — обложки через chafa или ImageMagick
    api.js        — Кинопоиск и Kinobox
    stream.js     — извлечение потока из iframe
    mpv.js        — запуск mpv
    config.js     — ~/.config/ktw/config.json
    ui.js         — вывод для построчного режима
```

## Если поток не нашёлся

- Попробовать другой балансер — их в списке обычно несколько
- Увеличить ожидание: `--timeout 90000`
- Посмотреть глазами, что происходит: `--headful`
- Не заработало нигде — открыть плеер как есть: `--iframe`

Часть балансеров недоступна вне РФ и отдаёт пустой ответ либо 5xx — в этом
случае не поможет ни один флаг, нужен VPN.
