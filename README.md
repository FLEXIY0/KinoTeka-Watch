# Ветка `claude/site-player-cli-9ly8ks` — терминальный клиент ktw

> Это заметка по ветке, а не описание проекта. Описание сайта — в файле
> `readme`, полная документация клиента — в [`cli/README.md`](cli/README.md).
> При вливании в `main` этот файл можно удалить.

Ветка добавляет `ktw` — терминальную версию KinoTeka Watch. Тот же поиск и те
же плееры, что на сайте, но полноэкранным интерфейсом в терминале и с выводом
потока в mpv. Сайт не тронут: все изменения лежат в каталоге `cli/`, плюс
`bin`/`scripts` в `package.json` и абзац в `readme`.

## Установка с этой ветки

`main` пока без `cli/`, поэтому ставить надо именно с ветки:

```sh
curl -fsSL https://raw.githubusercontent.com/FLEXIY0/KinoTeka-Watch/claude/site-player-cli-9ly8ks/cli/install.sh \
  | KTW_BRANCH=claude/site-player-cli-9ly8ks sh
```

Скрипт поставит недостающее (Node.js 18+, mpv, chafa, puppeteer с Chromium),
скачает исходники в `~/.local/share/ktw`, слинкует команду `ktw` в
`~/.local/bin` и спросит ключ API. Если репозиторий уже склонирован — просто
`sh cli/install.sh` из его корня, тогда ничего не скачивается.

Ключ Кинопоиска не обязателен: без него название уходит прямо в Kinobox,
который ищет по нему сам — смотреть можно сразу, но без обложек, описаний и
списка серий (сезон и серию тогда задают флагами `-s` и `-e`). Ключ всё это
добавляет; бесплатный выдаёт
[kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech), а вставить
его можно прямо в интерфейсе по `Ctrl+K`.

## Как проверять

По нарастающей — так сразу видно, какое звено отвалилось.

**1. API и зеркало живы**

```sh
ktw 301 --iframe
```

Ожидается имя балансера и ссылка на плеер:

```
▸ Alloha · Оригинальный
https://theatre.stravers.live/?token_movie=72d249c8bf…&translation=93&token=…
```

**2. Поток извлекается** — самое важное, ниже про это отдельно

```sh
ktw 301 --no-mpv
```

Ожидается ссылка на `.m3u8` и готовая команда mpv с Referer и User-Agent.

**3. Полный интерфейс**

```sh
ktw
```

Печатаешь название — под полем появляются похожие фильмы. Enter выбирает.
Для сериала спросит сезон, серию, плеер и озвучку, потом достанет поток и
отдаст его mpv. После выхода из mpv вернёт к списку серий.

Стоит потыкать по пути: `Esc` — шаг назад на любом экране, цифры `1`–`9` —
быстрый выбор, `PgUp`/`PgDn` в длинных списках серий, ресайз окна терминала.

**4. Сериалы, озвучки, качество**

```sh
ktw "во все тяжкие" -s 1 -e 3
ktw 464963 --player alloha --translation lostfilm --iframe
ktw 301 --quality 720 --no-mpv
```

Качество спрашивается после извлечения потока: клиент читает мастер-плейлист и
показывает дорожки с битрейтом. Флагом `-q` можно задать сразу — `1080`, `720`,
`max`, `min`.

### Если после установки `ktw: команда не найдена`

`ktw` — обычный скрипт, а не служба, поэтому init-система (sysvinit, OpenRC,
systemd) роли не играет. Не хватает только `PATH`:

```sh
~/.local/bin/ktw --help        # файл на месте, просто не виден по имени
export PATH="$PATH:$HOME/.local/bin"
```

В Debian-совместимых (Devuan, Loc OS, Ubuntu) `~/.profile` подхватывает
`~/.local/bin` сам, но только если каталог существовал на момент входа в
систему — а установщик создал его только что. После перелогина всё заработает
без правок.

## Что проверено, а что нет

Проверено на живых данных: поиск, карточка фильма, сезоны и серии, список
балансеров, 18 озвучек у «Игры престолов» на Alloha, подстановка `season`/
`episode` в ссылку, установщик целиком под dash, откат на системный Chromium.

**Не проверено: извлечение потока с настоящего балансера.** У браузера в моей
среде нет сети — `ERR_CONNECTION_RESET` и на балансере, и на `example.com`,
и напрямую, и через прокси, при том что curl до тех же хостов доходит. Так что
sniffer проверен только на локальном поддельном балансере: вложенный iframe,
кнопка play, рекламный preroll — фильтрация, приоритет `.m3u8` над `.mp4` и
вычисление Referer отработали верно. На живом Alloha или Collaps это звено
проверит твой первый запуск шага 2.

Если поток не находится:

| Что попробовать | Команда |
| --- | --- |
| Другой балансер | `ktw 301 --player collaps --no-mpv` |
| Больше времени | `ktw 301 --no-mpv --timeout 90000` |
| Посмотреть глазами | `ktw 301 --headful` |
| Убедиться, что дело не в извлечении | `ktw 301 --iframe` и открыть ссылку в браузере |

Часть балансеров недоступна вне РФ — тогда не поможет ни один флаг, нужен VPN.

## Что внутри

```
cli/
  install.sh      — установщик (POSIX sh, без systemd)
  ktw.js          — разбор аргументов, построчный режим
  lib/
    app.js        — экраны интерфейса и переходы между ними
    tui.js        — движок: кадры, клавиши, списки, рамки
    ansi.js       — цвета, ширина строк, рамки
    poster.js     — обложки через chafa или ImageMagick
    api.js        — Кинопоиск и Kinobox
    stream.js     — извлечение потока из iframe
    mpv.js        — запуск mpv
    config.js     — ~/.config/ktw/config.json
    ui.js         — вывод для построчного режима
```

Три решения, которые стоит знать при ревью:

**Поток берётся сниффером, а не разбором балансеров.** Прямую ссылку они не
отдают — её собирает их обфусцированный JS в браузере, у каждого свой и
постоянно меняется. Поэтому iframe открывается в headless Chromium, а из его
сетевых запросов забирается первый `.m3u8`. Один механизм на все балансеры
сразу вместо вечной гонки с каждым.

**Список плееров идёт через `fbphdplay.top`, а не `api.kinobox.tv`.**
Официальный хост отвечает не отовсюду, а `fbphdplay.top` — то самое зеркало,
с которого сайт грузит `kinobox.js`, и отдаёт оно ровно тот же JSON. Зеркала
перебираются по очереди, своё ставится через `KTW_KINOBOX_API`.

**Обложки рисуются символами, а не протоколами графики.** chafa в режиме
symbols отдаёт готовые строки, они становятся частью текстового кадра —
перерисовка не мерцает, ничего не надо стирать вручную, и это работает в любом
терминале вплоть до голой консоли. Без chafa подхватится ImageMagick, без
обоих — рамка с буквой.

Зависимостей для интерфейса нет вообще, только `readline` и escape-коды.
puppeteer нужен исключительно для извлечения потока — без него работает
`--iframe`. Сборщиков и новых пакетов не добавлено: `puppeteer` уже был в
`package.json`.

## Совместимость

Целевая система — Devuan, поэтому установщик написан на чистом POSIX sh
(проверен под dash) и systemd нигде не участвует. Пакеты ставятся через тот
менеджер, что найдётся: apt, apk, dnf, yum, pacman, zypper, xbps, brew. Root
запрашивается через sudo, doas или su — на минимальных системах sudo часто нет.

Интерфейс переживает отсутствие цвета (`NO_COLOR=1`), отсутствие Unicode
(`KTW_ASCII=1`), узкие окна (уже 66 колонок обложка убирается сама) и работу
без терминала — тогда включается построчный режим для скриптов и пайпов.
